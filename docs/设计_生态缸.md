# 设计：生态缸（让收获有去处）

> 目标：钓到的鱼、完成的任务不再只是图鉴里的数字——它们变成缸里的居民和建材，玩家亲手搭一个会呼吸的小生态，让这方世界更像一个游戏。
> 状态：第一期已实现（v0.6.0）：贝壳经济 + 商店 + 自由布置 + 生态评分 + 访客 + 珍珠 + 鱼的互动 + Web 全面屏。

## 调研：吸收了哪些开源 / 经典设计

只借思路、不搬代码（GPL / 非商用许可的项目尤其如此），所有像素画仍由代码绘制。

沿用 `设计_森林与水族馆.md` 的四条原则（永不封顶 · 非惩罚式累积 · 里程碑触发质变 · 给布置权），新增两条：

5. **收获要有去处**：每条鱼住进缸里、影响生态；每次专注和任务都换成贝壳，森林还会解锁沉木和苔藓球。
6. **反馈看得见**：缺氧时鱼聚到水面「浮头」、水质差时水色发浑、鱼群、爱心、珍珠泡泡——不看数字也知道缸怎么样。

## 核心循环

```
专注（满 5 分钟）─┬─> 钓到鱼 ──> 入缸（生机↑ 负担↑）──┐
                  └─> 贝壳（每 5 分钟 1 个）            │
完成任务 ─────────┬─> 贝壳（每个 2，每天前 12 个）      ├─> 生态评分 ─> 星级 ─┬─> 解锁新物件 / 扩缸
                  └─> 森林长树 ─> 解锁沉木、苔藓球    │                    ├─> 每天珍珠泡泡（点一下收集）
贝壳 ─> 商店（水草 / 造景 / 装饰 / 设备 / 生物 / 扩缸）─> 布置 ─┘                    └─> 访客条件
访客：缸的构成满足条件 ─> 下一次专注完成时游进来 ─> 首访谢礼贝壳 ─> 图鉴「访客」页
```

## 生态模型（`EcoTank.evaluate`）

- **负担** = Σ 缸内每条鱼的 `bioload`（`fish_data.json` 的 `eco` 字段：咸鱼 1、会议鲤鱼 3……）。
- **氧气** = (基础 6 + 2×缸级 + Σ 摆件氧) ÷ 负担，夹到 0–100%。
- **水质** = (基础 6 + 2×缸级 + Σ 摆件净 + 键盘泥鳅×2) ÷ 负担，夹到 0–100%。
- **美观** = Σ 摆件美观（同款只算前 3 件）+ 2×物件种类数 + 主题套组 + 鱼的喜好（周报河豚爱珊瑚、加班鳗鱼要有地方躲、沙丁鱼 5 条成群）。
- **生机** = 4×鱼种数 + 1×缸内鱼数 + Σ 鱼种等级 + 2×小生物 + 6×在场访客 + 好运鱼 10。
- **平衡系数** = 0.5 + 0.5 × min(氧气, 水质)：最差也只打五折。
- **评分** = (美观 + 生机) × 平衡系数；星级阈值 20 / 60 / 130 / 230 / 360。
- **解锁只看历史最佳星级**：拆掉装饰、鱼多到缺氧，都不会把已解锁的东西收回去。

**鱼种等级**：同一种鱼累计钓到 1 / 3 / 6 / 10 / 20 条升到 Lv.1–5，缸里的它会变大，Lv.5 身上有流光——重复的钓获也有意义。

**入缸**：按鱼种轮转，每轮各取一条，直到缸满，稀有鱼总能露面；图鉴里可以把某种鱼设为「留池塘」。

## 经济

| 来源 | 数量 |
|---|---|
| 专注 | 每 5 分钟 1 贝壳（不足 5 分钟不给，防 1 分钟刷），单次上限 24 |
| 完成任务 | 每个 2 贝壳，每天前 12 个 |
| 珍珠泡泡 | 每个新的一天按上次星级产出（★3 = 3 颗），每颗 2 贝壳；没领的会等着（上限 15） |
| 访客首访 | 15–60 贝壳谢礼 |
| 开缸礼 / 旧档补发 | 30 + 累计专注×5 + 累计任务×2（只发一次） |

价格：水草 10–24、造景 14–40、装饰 24–150、设备 45–70、小生物 28–32；扩缸 240 / 600 / 1200（容量 12 → 20 → 30 → 40）。同款每多一件贵 15%。

数值用 `EcoTank` 模拟了 60 天：每天 6 个番茄的玩家约第 7 天 3 星、第 14–21 天 5 星；每天 3 个番茄约第 7 天 3 星、第 30 天 5 星。之后的长线是扩缸、集齐访客、把每种鱼养到 Lv.5。调数值改 `scripts/eco_tank.gd` 顶部常量和 `data/tank_items.json`。

## 访客（`data/tank_items.json` → `visitors`）

| 访客 | 条件 | 动作 |
|---|---|---|
| 寄居蟹 | 缸里有海螺壳 | 在沙地爬 |
| 小海马 | 水草 ≥ 5 株 | 挂在水草边悬停 |
| 虾虎鱼 | 黑壳虾 + 至少一块石头 | 在沙地跳 |
| 小丑鱼 | 海葵 | 绕着海葵游 |
| 小章鱼 | 沉船或城堡 + 石头 ≥ 3 | 守在洞口 |
| 六角恐龙 | 沉木 + 苔藓球 ≥ 2（来自森林） | 在沙地慢慢走 |
| 萤光水母 | 生态 ≥ 4 星 | 缓缓漂 |
| 老乌龟 | 落地大缸以上 + 5 星 | 来回巡游 |

条件满足后，**下一次专注完成时**才游进来（Spirit City 式：专注是发现访客的途径），在奖励弹窗里报喜；条件不再满足时它「出门溜达」，恢复后自动回来，图鉴记录初次来访日期。

## 交互

- **看缸**：点水面投喂（鱼群追饵料、吃到冒爱心）；点鱼显示名字和等级，附近的鱼受惊窜开；点珍珠泡泡收集贝壳；点左上角星级打开生态报告。
- **布置**：水族馆右上角「布置」。底部库存条点一下把东西放进缸，拖动摆放——**左右 = 位置，上下 = 前后景深**（越靠前越大、越清楚）；工具条可「翻转 / 收回」。进入布置自动全屏。鼠标与触屏共用同一套事件（Godot 触屏模拟鼠标）。
- **全屏**：收起下方控制台，让房间占满窗口；控制台收起时左下角有迷你计时胶囊。

## 全面屏（Web / B站 Toy）

调研结论（Toy JS SDK 1.7.0 文档）：B站 Toy 的「全面屏」即容器的**沉浸模式**，需在页面里引入 SDK 后调用 `toy.setContainerMode({ immersive: true, orientation: 'portrait' })`；`toy.onContainerChange` 会推送 `safeArea`（状态栏 / 导航条占掉的区域，CSS 像素）。这些能力只在 B站 App 内可用，浏览器里 `isSupport` 为 false。

实现：

- **导出预设** `html/head_include`：异步引入 Toy SDK；给 viewport meta 补 `viewport-fit=cover`（否则 iOS 的 `env(safe-area-inset-*)` 恒为 0）。
- **`WebShell` 自动加载**：在 App 内请求「沉浸 + 竖屏」，订阅容器变化；取 Toy `safeArea` 与 CSS `env()` 的较大值，换算成设计像素后通知 main。
- **拉伸改为 expand**：以 400 宽为基准铺满任意长宽比，多出来的高度给场景（缸更高），不再上下留黑边；可见区 ≥ 600 宽（平板横屏 / 桌面浏览器）时控制台改回左右并排。
- **安全区**：顶栏向下加高并保持深色，与状态栏连成一片；左右下三边整体内缩。
- **`WebInput` 输入桥**：DOM 覆盖层的坐标换算改用 Godot 实际可见尺寸，不再写死 400×720。
- **中文换行**：开启 `internationalization/locale/include_text_server_data`（约 +4 MB），导出版的中文才能按字断行（Web 导出实测此前只会在空格处换行；该选项对所有导出平台生效）。

桌面调试手机布局：`godot --path . -- --web-layout --web-size=390x844 --safe-area=44,0,34,0`。

## 存档

新增 `save_data.eco`（结构见 `EcoTank.default_state()`）：贝壳、拥有 / 摆放的物件（`placed: [{uid, id, x, d, flip}]`，x / d 为 0–1 归一化）、缸级、历史最佳星级、入缸排除、访客、珍珠、迁移标记。`_merge_defaults` 自动回填，旧档首次打开时 `migrate_legacy` 一次性：补发贝壳、按已有鱼数给够缸位、把旧版珊瑚 / 沉船 / 宝箱按原开关与槽位摆回缸里。

## 第二期候选

- 访客离开时留下纪念品装饰（Neko Atsume 的「宝物」）。
- 花色 / 染色：完成任务掉落「颜料」，给鱼换配色（Habitica 孵化药水）。
- 水族协会委托（Stardew 收集包）：登记指定的鱼而不消耗，完成解锁新群系。
- 群系：淡水 → 珊瑚礁 → 深海（暗水 + 夜光鱼 + 可摆放的灯）。
- 昼夜：按本地时间调水色，夜里加班鳗鱼更活跃。
- Toy 云存档：`setCloudStorage` 限 128 键、单值 ≤ 1 KB，需分片 + 只在检查点写入。
