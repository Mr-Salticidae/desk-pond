# 设计：v0.7 每日记录、角落小窗、到点提醒、昼夜与新版本提示

> 目标：让工位池塘更像一个「整天开着也不碍事」的桌面陪伴——能缩到屏幕角落，到点叫得醒你，跟着一天的光线变化；同时从这一版开始按天记账，给以后的回顾功能攒数据。
> 状态：已实现、未发版（2026-10-07）。第八节七项取舍作者全部采用推荐方案；实现中和设计稿不一样的地方见第十节。

## 为什么是这五件

v0.6.2 之后对着代码盘了一遍现状，这五件各对应一个具体的缺口：

| 缺口 | 现状（代码依据） | 本版对策 |
|---|---|---|
| 没有按天的历史 | 存档只有「今天」（`pomodoro_completed` / `tasks_completed`，跨天清零）和「累计」两层 | **每日记录**：每天一行，只增不减 |
| 窗口缩不小 | 桌面版 `min_size = 640×520`，只能放大 | **角落小窗**：一条可置顶的迷你窗 |
| 到点容易错过 | 专注结束只在窗口里弹奖励、响两声；**休息结束完全无声**（`break_completed` 信号没有任何地方接） | **到点提醒**：任务栏闪烁 + 休息结束也提醒 |
| 画面一整天不变 | 三个房间的颜色都是常量 | **昼夜**：跟着本地时间换光线 |
| 用户拿不到修复 | exe 免安装，没有更新渠道；issue #1 的修复在 main 上躺了 82 天才发版，报告者一直以为没修 | **新版本提示**：启动时查一次版本号 |

这五件不改任何玩法数值，不动生态缸，旧存档直接兼容。生态缸第二期、森林、任务与专注挂钩、存档导出留到 v0.8 以后（见第七节）。

建议开工顺序：每日记录 → 到点提醒 → 角落小窗 → 昼夜 → 新版本提示。前两件小、互不依赖，先落地；小窗改动最大、风险最高，放在第三件，早暴露问题。

## 1. 每日记录

### 记什么

`save_data.daily`：以日期为键，每天一行，键名压短（日后接云存档时单值有大小上限，Toy 云存储单值 ≤ 1 KB）：

```json
"daily": {
  "2026-10-07": { "m": 75, "n": 3, "t": 4, "s": 21, "f": { "salted_fish": 2, "weekly_pufferfish": 1 } }
}
```

| 键 | 含义 | 什么时候加 |
|---|---|---|
| `m` | 专注分钟 | 专注完成时加 `last_focus_seconds / 60`（倒计时 = 设定时长，正计时 = 实际时长，和贝壳同一口径） |
| `n` | 完成的专注次数 | 专注完成时 +1 |
| `t` | 完成的任务数 | `task_completed` 信号 +1。这个信号每个任务只在第一次完成时发，和 `total_tasks_completed` 同口径，反复勾选刷不了 |
| `s` | 当天获得的贝壳 | 所有贝壳入账处 +N |
| `f` | 当天钓到的鱼 | 专注完成时按鱼种 +1 |

- **只增不减**：取消勾选任务不扣 `t`，和累计数一致。
- **记在完成那一刻的日期上**：零点前开始、零点后结束的专注记到新的一天，和现有换天逻辑一致。
- **体积**：一天约 60–100 字节，一年 20–40 KB，全部保留，不做清理。
- **旧存档**：v0.7 第一次打开时给今天补一行，`n` / `t` 取当天已有的计数，`m` 无从得知记 0。更早的历史补不回来，界面上不假装有。

### 怎么看

v0.7 只做最小的展示，放在「档案」里：

- **最近 14 天**：一排小柱，高度 = 专注分钟，柱下标日期；点一根柱子显示那天的专注、任务和钓获。
- **本周合计**：专注 N 分钟 · 完成 N 个任务 · 钓到 N 条鱼。
- **不做连胜，不标红**：空白的日子只是一根没有高度的柱子，不写「断签」「未完成」。沿用「永不封顶 · 非惩罚式累积」的原则。

月历热力图、周报卡片、按任务统计等到 v0.8 以后，数据攒够了再做。

### 实现要点

- 新增 `scripts/daily_log.gd`（`RefCounted`，纯逻辑，和 `EcoTank` 一样绑定存档字典按引用修改），提供 `add_focus(minutes, fish_id)`、`add_task()`、`add_shells(n)`、`recent(days)`。
- `main.gd` 在 `_on_focus_completed`、`_on_task_completed` 各调一次。贝壳的来源有好几处（专注、任务、珍珠、访客谢礼……），但都经过 `EcoTank.earn()`，在那里加一个入账回调，集中记 `s`。
- 测试 `tests/test_daily.gd`：累加、跨零点、取消勾选不扣、旧存档补今天、`recent()` 补空日。

## 2. 到点提醒

| 时刻 | 现在 | v0.7 |
|---|---|---|
| 专注结束 | 窗口内奖励弹窗 + 提示音 + 钓获音效 | 不变；另外窗口不在前台时让任务栏闪烁 |
| 休息结束 | 静默回到待机 | 轻提示音 + 池塘状态文字「休息好了，点池塘再甩一杆」+ 任务栏闪烁 |

- 任务栏闪烁用 `DisplayServer.window_request_attention()`：Windows 上任务栏按钮闪烁，macOS 上 Dock 图标跳动；窗口已在前台时不调用。
- 不抢焦点：不自动把窗口提到最前，不打断正在打字的人。
- 声音跟随现有的静音开关；闪烁不受静音影响（静音的人更需要它）。
- 休息结束**不自动开始下一轮专注**，节奏留给玩家自己定。
- 系统通知（Windows Toast、macOS 通知中心）Godot 没有内置接口，要另接扩展，这一版不做。
- 需要的新素材：一个比专注结束更轻的提示音，沿用 v0.5.0 合成音效的做法。

## 3. 角落小窗

### 样子

```
┌──────────────────────────────────────────┐
│ ≈≈ 🎣 ≈≈≈ 🐟 ≈≈≈≈   专注中 18:42  [收竿] [展开] │   300 × 84
└──────────────────────────────────────────┘
```

- **左边一小块水面**：钓鱼人和水面的简化版。专注时甩着竿，钓到鱼时水面闪一下。
- **右边计时 + 主按钮**：待机时「甩杆」，倒计时专注中「暂停」，正计时专注中「收竿」，休息中显示休息倒计时。
- **「展开」按钮**：回到完整窗口，恢复进入小窗前的大小和位置。

### 怎么进出

- 顶栏新增一个「小窗」图标按钮（放在置顶按钮左边；顶栏宽度预算要重算，见下文）。
- 进入小窗时：
  - 窗口贴到**当前屏幕可用区域的右下角**（避开任务栏），留 12 px 边距；
  - 自动置顶，退出小窗后恢复原来的置顶设置；
  - 记住小窗被拖到的位置，下次进入直接回到那里。
- 小窗整条都可以拖动（按钮除外）。
- 双击小窗或点「展开」展开。

### 小窗里专注完成

不弹完整奖励窗（会把小窗撑开、挡住别的窗口）。小窗内冒一个 3 秒的气泡「钓到周报河豚 · +5 贝壳」，同时发任务栏闪烁；完整的奖励列表（访客到访、里程碑赠礼）在下次展开时补弹一次。

### 实现要点

- **同一个窗口切两套布局**，不新开 `Window`，省得处理两个窗口的焦点和置顶：进入小窗时隐藏顶栏、场景区和控制台，显示新的 `MiniBar` 控件；把 `min_size` 降到小窗尺寸再缩窗口，退出时反过来。
- **新写 `scripts/mini_bar.gd`**，不复用 `PixelWorld`：`PixelWorld` 里桌子、钓鱼人用的是固定像素尺寸（桌子 108 px 宽），压到 84 px 高会画乱。`MiniBar` 只画水带、钓鱼人、三条鱼影，代码量小。
- **计时**：继续由 `pomodoro_panel` 驱动（节点在小窗模式下只是隐藏，照常 tick），`MiniBar` 订阅 `timer_tick` / `state_changed`，和现在的全屏计时胶囊同一做法。
- **存档**：`settings.mini = { "on": false, "pos": [], "full_pos": [] }`。上次在小窗里关掉的，下次启动直接是小窗。
- **顶栏宽度预算**：多一个按钮，要重算 640 宽的顶栏。`tests/test_layout.gd` 在所有房间 × 窗口尺寸下断言按钮都在窗口内；小窗自己的布局由 `tests/test_mini.gd` 守。
- **透明圆角**：Godot 支持逐像素透明窗口，能做成悬浮胶囊的样子，但不同显卡和系统上的表现要逐一验证。v0.7 先做不透明矩形，透明留作打磨项。
- 只有桌面版有小窗；Web / 手机版本来就是整屏，不需要。

## 4. 昼夜

### 时间段

按**本地时间**，四段之间用约 1 小时平滑过渡，不跳变：

| 时段 | 时间 | 天空 / 光线 |
|---|---|---|
| 清晨 | 05:00–08:00 | 淡粉橙，光线偏暖 |
| 白天 | 08:00–17:00 | 现在的配色（基准） |
| 黄昏 | 17:00–19:00 | 橙红，影子拉长感 |
| 夜晚 | 19:00–05:00 | 深蓝，整体压暗 |

### 每个房间的变化

- **池塘**：夜里云换成星星，工位上的显示器亮起冷光——夜里还在甩竿的人，屏幕也亮着。
- **森林**：夜里亮起萤火虫。`设计_森林与水族馆.md` 里「夜萤」一直留待打磨，这次顺手兑现。
- **水族馆**：水色整体变深，气泡石的气泡和萤光水母（有的话）在夜里更显眼。加班鳗鱼夜里游得更快更勤（`设计_生态缸.md` 第二期候选里的那一条）。

**只改画面，不锁内容**：不做「只有夜里才来的访客」「只有早上才钓得到的鱼」。白天上班和夜里加班的人，能收集的东西一样多。

### 实现要点

- 新增 `scripts/day_cycle.gd`（autoload）：
  - 每分钟算一次 `night`（0–1）和当前时段配色，变化时发 `changed` 信号；
  - 三个房间的 `_draw()` 里：天色直接取 `DayCycle.sky`，其余照常画完后统一压一层 `DayCycle.overlay` 遮罩，夜里的光源（显示器、萤火虫、发光物件）画在遮罩之上。
- **不用 `CanvasModulate`**：它会连 UI 一起压暗；只染场景，不染按钮和文字。
- **调试参数** `-- --hour=21`：截图和测试用，不用等到晚上。
- **设置**：「跟随本地时间 / 一直白天」，默认跟随。
- **思路来源**：Orb.Farm（MIT）的昼夜参数和亮度调制；和 `设计_生态缸.md` 一样只借思路、不搬代码。
- **测试** `tests/test_day_cycle.gd`：
  - 各时间点的时段对不对；
  - 相邻分钟的颜色差不超过阈值（过渡不跳变）；
  - 23:59 → 00:00 连续。

## 5. 新版本提示（桌面版）

- **数据源：自有站 `https://tiaozhuxiansheng.com/desk-pond/latest.json`。**
  - 自有站部署时，本来就有一步从 Release 拉 exe；同一步顺手写这个文件：`{"version": "0.7.0", "url": "下载页", "notes": "一句话更新说明"}`。
  - 走香港服务器，国内能直连；不直接查 GitHub API，因为国内访问不稳。
- **时机**：启动后 10 秒查一次，每天最多一次，超时 5 秒；失败静默，不弹错。
- **比对**：和 `ProjectSettings.get_setting("application/config/version")` 按 `x.y.z` 逐段比较。
- **提示**：有新版时，顶栏「?」按钮上亮一个小点；玩法说明顶部出一行「有新版本 v0.7.1：一句话说明 [去下载]」，点击用 `OS.shell_open` 打开下载页。不自动下载，不自动安装。
- **隐私**：请求不带任何玩家数据，就是一次普通的 GET。README 写明；设置里可以关。
- Web / Toy 版不需要，平台自己会更新。
- 测试：版本号比较的单元测试（`0.7.0 < 0.7.1 < 0.10.0`，带 `-beta` 后缀的情况）。
- **自有站这一步还没做**：`above-the-web` 的 `.github/workflows/deploy.yml` 里「拉取 desk-pond 最新 Release 安装包到 dist」一步，发 v0.7 时追加（文件不存在时应用静默跳过，不影响使用）：

  ```bash
  curl -sL -H "Authorization: Bearer $GH_TOKEN"     https://api.github.com/repos/Mr-Salticidae/desk-pond/releases/latest     | jq '{version: (.tag_name | ltrimstr("v")), url: "https://tiaozhuxiansheng.com/desk-pond/", notes: ((.body // "") | split("
")[0] | .[0:60])}'     > dist/desk-pond/latest.json
  ```

## 6. 存档变更

| 字段 | 默认值 | 说明 |
|---|---|---|
| `daily` | `{}` | 每日记录，见第一节 |
| `daily_since` | `""` | 开始记录的那天；之前的日子没有按天的数据 |
| `settings.mini` | `{"on": false, "pos": [], "full_pos": []}` | 小窗开关、小窗位置、进小窗前完整窗口的位置 |
| `settings.day_cycle` | `"auto"` | `"auto"` 跟随本地时间 / `"day"` 一直白天 |
| `settings.update_check` | `true` | 新版本检查开关 |
| `update.last_check` | `""` | 上次检查成功的日期，控制每天最多一次 |
| `update.latest` | `{}` | 查到的更新版本 `{version, url, notes}`，没有更新时为空 |

全部由 `_merge_defaults` 自动回填，旧存档无需迁移脚本（`daily` 的「补今天」除外，见第一节）。分享码格式不变。

## 10. 实现记录（2026-10-07）

**和设计稿不一样的地方**

| 设计稿 | 实际 | 原因 |
|---|---|---|
| 顶栏「小窗」文字按钮 | 像素图标按钮（窗口外框 + 右下角一小块水色），代码逐像素生成，和贝壳图标同一做法 | 顶栏在 640 宽时只富余 2 px，两个字就会把统计文字挤成省略号。换成图标后统计文字仍会被压缩，所以给它加了悬停提示，鼠标放上去能看到完整数字 |
| 展开按钮 `⤢` | 「展开」两个字 | 像素字体里没有这个符号 |
| 各房间把常量颜色逐个 `lerp` 到夜色 | 天色取 `DayCycle.sky`，其余画完后统一压一层遮罩，光源画在遮罩之上 | 一处改动覆盖全部元素，白天时遮罩透明，和 v0.6 完全一致 |
| — | 池塘夜里加了一弯月亮 | 夜空只有星星时太空 |
| — | 分享卡片里的缸永远是白天 | 卡片是一张「照片」，朋友收到的图和白天看到的一致 |
| — | 森林萤火虫的数量随林子变多（6–24 只） | 让「完成任务」这条线在夜里也看得出积累 |
| 检查失败静默 | 连不上不记检查日期，下次启动再试；文件 404 当作没有新版；只接受 https 链接；说明文字截到 60 字；无头运行（测试 / CI）不联网 | 防止一次断网吞掉当天的检查，也防止版本文件被塞进奇怪的链接 |
| 小窗布局测试放进 `test_layout.gd` | 单独的 `test_mini.gd` | 小窗还要测按钮行为、报喜和补弹，放一起太杂 |
